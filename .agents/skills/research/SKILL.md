# Research

Start with the decision the research must inform. Define the question, required confidence, scope, and what evidence would change the decision.

Prefer original papers, standards, official documentation, first-party source code, and authoritative datasets. Trace important claims to the source that owns them. Record version, date, section, equation, API surface, or commit when precision matters.

Separate:

- directly supported findings;
- interpretations or cross-source synthesis;
- unresolved conflicts;
- assumptions and missing evidence;
- consequences for the originating decision.

Use short quotations only when exact language matters; otherwise paraphrase with a nearby citation. Do not turn research into a design decision without returning the trade-off to the user or enclosing workflow.

Produce a concise cited result in the location requested by the user or enclosing workflow. If it belongs on GitHub, invoke `git` to publish or link it only when authorized.
