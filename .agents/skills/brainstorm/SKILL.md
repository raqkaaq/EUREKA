# Brainstorm

Invoke `interviewing` and conduct a decision-focused conversation.

Remain artifact-free: do not edit documents, code, Git state, or GitHub state. Look up facts that can be established from available sources rather than asking the user to supply them. Put choices, priorities, and trade-offs to the user.

Finish only after the user agrees that the important branches have been explored. Summarize settled decisions, rejected alternatives, assumptions, and open questions. Recommend `design-session`, `research`, `prototype`, `map-work`, or `specify` when one is the natural next step, but do not start it automatically.
