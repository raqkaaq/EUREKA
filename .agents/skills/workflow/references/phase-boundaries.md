# Phase Boundaries

Choose between phases, not mid-thought:

1. **Continue** when the next phase needs this conversation and context remains useful.
2. **Start fresh** when durable artifacts contain everything needed next.
3. **Handoff** when context must travel to another person, harness, repo, or side task.
4. **Delegate** when bounded work can run without steering and report back.
5. **Compact** when context matters, interaction must continue, and the cheaper options do not fit.

Everything except continuing replaces primary conversation with a lossy artifact. Name what the next phase needs before paying that cost.
