# Project Status

Derive status from issues, PRs, dependencies, milestones, branches, and commits—not a duplicate progress document.

Report named items under:

1. Needs human attention
2. Ready frontier
3. Active implementation
4. Waiting for review or merge
5. Blocked or stale
6. State discrepancies

Check for new activity on `needs-info`, untriaged work, closed blockers, abandoned claims, branches without PRs, PRs without issues, and merged work whose issue or follow-up state is wrong.

Order by explicit priority, dependency impact, then age. State the evidence for the recommended next action. Reading status does not authorize mutations.
