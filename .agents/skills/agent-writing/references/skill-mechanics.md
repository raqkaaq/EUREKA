# Skill Mechanics

## Invocation

A model-invoked skill pays context load for automatic discovery. An explicit-only workflow saves that load but adds cognitive load for the user. Choose deliberately.

A description is a context pointer: front-load its leading word and name each distinct trigger branch once. Synonyms do not create new branches.

## Routers

A router names when to use each independent workflow; it does not repeat their procedures.

## Progressive Disclosure

Keep universal steps in `SKILL.md`; move branch procedures to references with explicit loading conditions. Co-locate a concept's definition, rules, and caveats. Use scripts for deterministic repetition and assets for output material. Split when a capability needs independent discovery or visible later steps repeatedly rush the current one.
